# Offline crowd and voice exploration

This is a local experiment alongside the existing Agentic OBS prototype. It does not select a streaming platform, connect to Twitch, subscribe to anything, call a provider, or touch OBS. It reuses the existing overlay renderer and validator.

Run `python3 -m unittest test_mock_eventsub test_mock_transport -v` then `python3 replay_mock_eventsub.py /absolute/new/proof-directory`. Requires the existing Python environment's websockets15 and Playwright Chromium. The proof owns only controller127.0.0.1:8881 and mock WebSocket127.0.0.1:8882 and closes both afterward. It launches a headless browser for functional DOM assertions, with no screenshots. The wrapper strips OpenAI variables, forces Codex off and refuses non-rules planners. All inputs start off. The replay explicitly enables chat and synthetic-transcript voice for its demonstration, turns them off, then terminates its controller.

Demo sequence: open the overlay; explicitly enable the local mock input; ordinary chat does nothing; `!overlay party` creates the fixed emoji burst. A duplicate and stale event do nothing. A local session-reconnect envelope opens the replacement socket, receives welcome, then closes the old socket; the duplicate ID remains ignored. A mocked known reward displays the fixed `Hydrate!` text, regardless of user_input. A synthetic `Director caption Offline voice transcript` cue displays a lower third. This last step is not microphone/ASR proof. The interface labels viewer input CHAT SIMULATOR.

Viewer strings never become prompts, overlay text, tools or shell commands. Only three exact chat strings and a single known mock reward ID map to fixed existing rule cues. Wrong channel, wrong subscription version, malformed envelopes, stale/future timestamps, pre-welcome notifications and remote reconnect URLs are refused. Seen envelope IDs are retained across reconnect, bounded at4096; this is an in-memory demonstration, not durable exactly-once delivery. Revocation, timeout and disconnect leave the adapter off. Keepalive loss fails closed; automatic loss recovery/resubscription and event replay after network loss are not implemented. Reconnect overlap is exercised with the mock only. No live subscription creation or OAuth exists.

Official shapes and protocol were checked against Twitch's Handling WebSocket Events and EventSub Reference on28Oct2026. Synthetic fixtures use channel.chat.message and channel.channel_points_custom_reward_redemption.add field names, but are not evidence of Twitch delivery or affiliate reward eligibility. Twitch CLI does not supply the chat replay here: the local mock does. The parser validates the fields it consumes, not every optional field in the official schema.

No native OBS calls exist in this slice. The exercised HTTP routes for StartStream, TriggerHotkeyByName and SetStreamServiceSettings return404. Program control, audio hardware, live Twitch chat/rewards, OAuth, streaming, recording and virtual camera remain outside this proof. Existing8878/8879 controllers are untouched. Codex tool-isolation and latency gaps remain unresolved; this experiment does not enable that model planner.
